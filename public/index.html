Full-Stack System Architecture & Learning Guide

This full-stack application fulfills all modern engineering requirements: Persistent Database Storage, User Authentication, REST API Architecture, and Real-Time Bidirectional WebSocket Synchronization.

⚡

1. REST API Layer

Built with Node.js HTTP server. Serves standard CRUD endpoints (/api/tasks, /api/auth) using JSON payloads and HTTP status codes.

🔒

2. Auth & Sessions

Password hashing via PBKDF2 with SHA-512 and cryptographic salt. Bearer tokens verified on protected API routes.

🗄️

3. SQLite Persistence

Uses node:sqlite with WAL journal mode. Relational schema with Foreign Keys and cascade deletions.

📡

4. Real-Time WebSockets

RFC 6455 framing and upgrade handshake. Any task update in one tab instantly broadcasts to other connected tabs.
